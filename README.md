## 👨‍💻 About

QA Automation Engineer with **3+ years** of experience building test automation for enterprise web applications, and an **ISTQB CTFL v4.0** certified tester. I test like an engineer and build like one too: Playwright suites in CI, REST API validation, database checks, and enough React to fix the UI bugs I find.

I'm working toward an **SDET** role, and I like testing the parts that don't show up in a defect count: clear documentation, honest traceability, and catching problems in planning instead of production.

## 🔭 What I'm working on now

- 🧭 Defining the **QA process (STLC)** for products built in an AI-driven development lifecycle: stage-by-stage activities, handoffs, and entry/exit criteria
- 🤖 Building **AI-assisted QA skills**: a testability review at product intake, and a test case generator that turns requirement documents into test cases using **Playwright MCP**
- 🧪 Practising **LLM evaluation** with DeepEval and pytest
- 🎯 Growing from QA automation into **SDET**
